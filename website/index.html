Terminal-Native TUI

Built with React & Ink. Features socket-level DNS/TLS metrics, interactive parameter editors, pretty JSON viewers, and production safety guards.

.apix Project Format

A single human-readable YAML file containing API endpoints, environments, auth profiles, saved requests, workflows, and contract assertions.

10-Language Generator

Instantly converts any discovered operation into syntactically valid code snippets for cURL, JavaScript, TypeScript, Python, Go, Rust, and more.

VS Code & CI Integration

Execute requests directly inside VS Code with CodeLens ▶ Run Request or automate API contract testing in GitHub Actions with apix test --ci.

Introduce .apix

One version-controlled file for your entire API lifecycle. Commit api.apix to Git to share workflows, tests, and requests across your development team.

# api.apix version: 1 name: Homely API baseUrl: "{{baseUrl}}" environments: development: baseUrl: "http://localhost:4000" requests: - name: List Users method: GET path: /users tests: - expect: status: 200
